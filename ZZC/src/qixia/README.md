# 星晖古境

## Product
A standalone web experience in zzcspace.com. The user confirmed a personal theme while retaining the reference's Chinese architecture and its interactive exploration. Nine imagined buildings connect to the existing personal introduction, photography, learning, music, interests and journal content. The model is an artistic courtyard, not a historically surveyed site.

## Visual direction
The supplied screenshot is the visual authority: an elevated courtyard diorama, large Chinese serif copy on the left, spare museum-like controls, selectable buildings, three camera presets, orbit, reset and time-of-day selection. Name: 星晖古境. Author: 曾子丞. Keep the blog's other pages unchanged.

Midnight blue atmosphere, aged gold typography, jade tiled roofs, vermilion columns and amber window light. Real geometry, curved roof profiles, batched tiles and lattice details; gradual camera easing, directional shadows, restrained bloom and suspended dust. Desktop gives the world most of the viewport; mobile keeps controls reachable and text brief. Reduced motion disables automatic camera and dust animation. Sound is optional and starts only after a gesture.

## Acceptance
Drag / touch rotation, wheel / pinch zoom, nine clickable architecture targets and list-based access. Previous/next updates descriptions and camera. Overview, axial and overhead presets, automatic orbit, reset, dawn/dusk/night, optional ambient sound, fullscreen, keyboard help. Each personal destination opens from the information panel. Screenshot checks on desktop and mobile and runtime checks for camera, lighting and selection. Separate lazy entry at /portfolio/qixia/ to avoid loading the world on existing pages.
