# 樱花公路

位于 `/game` 的单机 3D 街机竞速游戏。保留原版樱花主题，用 Three.js 程序化场景替代原来的 Canvas 伪 3D 渲染。所有车辆、赛道、标牌与声音均在本机生成，无外部模型、贴图或游戏服务依赖。

## 已有玩法

- 樱花公路、晴海环线，两条闭合赛道，分别宽 30 米和 28 米。
- 三款赛车，独立极速、加速、操控、氮气参数。
- 竞速赛（玩家 + 7 位 AI）、单人计时赛、不限圈数的自由练习。
- 1 / 2 / 3 圈，三档 AI 难度；AI 会提前减速、选择空车道、漂移、集气和在直道释放氮气。
- 漂移集气，松开触发小喷；两瓶氮气储量、加速带、碰撞减速和护栏。
- 倒计时、实时排名、小地图、分圈计时、结算、本机纪录。
- 暂停 / 继续、重新发车、回车库、回正、后视镜、全屏、音效和画质选择。
- 键盘与多指触屏输入；窗口失焦或切到后台会自动暂停并清空按键。

## 操作

| 输入 | 功能 |
| --- | --- |
| WASD / 方向键 | 油门、刹车、左右转向 |
| Shift + 方向 | 漂移；松开 Shift 后小喷 |
| 空格 | 消耗一瓶氮气 |
| P / Esc | 暂停或继续 |
| Q | 按住查看后方 |
| R | 回到赛道中央，停车两秒，对手继续行驶 |
| Enter | 从车库发车 |

自动油门默认开启，可以在车库关闭。手机按住方向、漂移、氮气等按钮，可多指组合操作。手机横屏或全屏能获得更宽的驾驶视野。

## 实现与验证

- `race-model.ts`：固定 120 Hz 模拟，与浏览器和渲染无关。赛道使用弧长采样，AI 使用相同进度、碰撞与充能状态；追赶辅助只在小范围调整速度，不修改位置。
- `race-world.ts`：3D 场景、实例化树木、车辆、跟随镜头、粒子、小地图和合成声音，卸载和重选赛道时释放 GPU 资源。
- `RacerGame.tsx`：生命周期、按键缓冲、多指输入、车库、仪表、结算和 localStorage。3D 模块仅在客户端动态载入。
- `racer.module.css`：桌面、竖屏、横屏、全屏布局和减少动态效果支持。

从仓库根目录运行：

```sh
node --test scripts/racer.test.mjs
npm --prefix XHBlogs run build
```

Node 24 可直接加载测试引用的 TypeScript。测试涵盖赛道闭合、完整比赛、固定步长、AI、漂移、氮气、碰撞、暂停与重置。游戏采用易上手的赛道相对坐标驾驶模型，并非真实轮胎物理模拟或联网比赛。

纪录键按赛道、赛车、模式、圈数和难度隔离。localStorage 不可用时比赛仍能正常完成。WebGL 2 不可用或上下文丢失时展示错误与重试入口。
